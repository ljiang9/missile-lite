# missile-lite 🚀

极简「导弹指挥官」克隆：敌方导弹从天而降瞄准你的 6 座城市，
你从 3 座炮台发射拦截弹，在空中引爆、用爆炸半径消灭来袭导弹。

- 纯 Python 标准库（`argparse / sys / random / math`），Python 3.10+
- 无头 AI 演示：`--auto` 看 AI 自动拦截
- 中文界面

## 玩法

- 每波 N 枚敌导弹（`--missiles`，默认 8），共 `--waves` 波（默认 3）
- 拦截弹从炮台飞往你指定的坐标，到达后爆炸，半径 3 格内敌导弹全部被摧毁（+25 分/枚）
- 炮台弹药有限（每座 10 发），打完就没了；炮台被直接命中会被摧毁
- 敌导弹落地会摧毁 2 格内的城市；每波结束每座存活城市 +100 分

## 用法

```bash
python -m missile_lite            # 交互模式（需要终端）
python -m missile_lite --auto     # AI 无头演示
python -m missile_lite --auto --seed 42 --waves 5 --missiles 12 --verbose
```

交互命令：`fire <炮台0-2> <x> <y>`（如 `fire 1 20 5`），`q` 退出。

## 真实验证

- `python3 -m py_compile missile_lite.py __main__.py` → 通过
- 拦截弹爆炸半径 3 格内敌导弹被摧毁并 +25 分 ✅
- 敌导弹落在城市 2 格内 → 城市被摧毁 ✅
- 炮台 10 发打完后 `fire` 返回 False，无法再发射 ✅
- `--auto` 5 个种子全部正常结束，无崩溃 ✅
  - 默认难度（3 波×8 枚）：`得分 2400，击杀 24，存活城市 6/6`（AI 全拦截）
  - 高难度（5 波×16 枚）：`得分 1625，击杀 29，存活城市 0/6`（AI 会漏，游戏如实结束）

## 已知局限

- **无实时键盘输入**：交互是"每行一个命令"的回合制，不是实时动作游戏
- `--auto` AI 是简单规则演示（预测拦截），高波次+高密度下会漏掉导弹
- 无音效、无最高分存档、无难度曲线
